# GitHub Pages data endpoint

This package publishes the contents of `data/` to GitHub Pages after each successful sync.

Public base URL:

`https://jetj1992.github.io/fpl-draft-8905-data`

Important public files:

- `/data/summary.json`
- `/data/current/transactions-enriched.json`
- `/data/current/post-gameweek-transactions.json`
- `/data/current/current-rosters.json`
- `/data/current/free-agents.json`
- `/data/current/proposed-waivers.json`

The recap process should prefer GitHub Pages over `raw.githubusercontent.com` to avoid stale web-cache results.
